ATS integrations & evidence-aware AI assessment

AI Job Hunter

An open-source Python CLI that discovers jobs from Greenhouse, Lever and Ashby, screens them against a configurable candidate profile, and produces explainable recommendations. An optional Gemini assessor compares technical requirements with documented candidate experience.

What this proves: I can integrate external data sources, combine deterministic rules with structured LLM output, validate evidence, and investigate failures through reproducible evaluations.

  • Public ATS APIs → Pydantic validation and deduplication → SQLite tracking → Markdown reports
  • Hard eligibility constraints stay separate from ranking; AI cannot override a deterministic review or rejection
  • Structured technical assessments with employer and candidate quotation checks; unverified mandatory skills require review
  • Offline labeled fixtures, optional live Gemini regressions and saved JSON report comparisons
  • Bounded retries, partial discovery recovery, structured logs, latency and token-usage reporting
Engineering decision

Keep hard rules authoritative and treat model output as untrusted. Validate quotations against the job description and recorded experience; missing or invalid evidence leads to review. Quotation provenance establishes where evidence came from, not whether it proves a skill.

Evaluation evidence

The documented deterministic baseline matched 12/12 curated reference labels; a separate focused live Gemini regression baseline passed 4/4 cases. These small regression datasets help catch known mistakes; they do not establish accuracy on unseen jobs.

Production infrastructure & DevOps

Production Infrastructure & Deployment

Designed and deployed a Docker-based VPS environment hosting this portfolio, the Vouchers frontend and Laravel API, and the public Moja Biblioteka website across six hostnames.

What this proves: I can design service boundaries, configure HTTPS and reverse proxy routing, isolate databases and application processes, migrate an existing deployment, and verify services after release.

  • Caddy routing with HTTPS and multi-domain hosting
  • Docker Compose orchestration and private service networks
  • Nginx → PHP-FPM → Laravel with persistent MySQL storage
  • Container image publishing and local integration testing
  • Deployment health checks and documented rollback steps
Engineering decision

Only Caddy publishes web ports on the VPS. The Laravel runtime and MySQL remain on Docker-internal networks; Nginx handles HTTP and forwards PHP requests to PHP-FPM.
